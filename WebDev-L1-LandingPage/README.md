# Northfold — Landing Page

**Track:** Web Development & Designing | **Level:** 1 | **Task:** 1 — Landing Page

## Objective
A static landing page for Northfold, a fictional small-batch, direct-trade coffee roastery. Built to practice foundational HTML5/CSS3 layout, responsive design, and visual hierarchy.

## Tech Stack
- HTML5
- CSS3 (Flexbox + Grid, no JavaScript)
- Google Fonts (Fraunces + Inter)

## Features
- Sticky navigation bar with 3 links (Beans, How it Works, About)
- Hero section with headline, subheadline, and CTA button
- 2 content sections: "How it Works" (3-step process) and "Testimonials"
- Footer with contact and social placeholders
- Consistent warm, coffee-inspired color palette
- Fully responsive layout (tested down to mobile widths)
- Clean typography using a serif/sans-serif pairing

## How to View
Open `index.html` in any browser — no build steps required.
